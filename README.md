# Utak

A starting point for an interactive visualization and explorable-explanations project.

The direction is to make ideas easier to understand by letting people explore them. This project is inspired by interactive explanations and visualizations; it does not yet contain a working application.

## Status

Project created. The concept, scope, and first prototype are still to be developed.
